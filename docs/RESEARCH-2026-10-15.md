# Voice-agent stack research: HeyGen, Retell AI, RingCentral, ElevenLabs/Cartesia

Research date: 2026-10-15. Sources are official docs and pages (plus two official community forums where noted). "UNCONFIRMED" means I could not verify it in official docs.

---

## TL;DR

- **HeyGen can clone Molly's voice and has a public standalone TTS API with an SSE streaming endpoint.** That voice cannot be loaded into Retell: Retell's voice providers do not include HeyGen, and HeyGen documents no way to export a voice. Retell can't stream audio from an external TTS either, so HeyGen is a dead end for live calls through Retell.
- **Retell is a good fit for outbound calls.** It offers `POST /v2/create-phone-call`, a custom-LLM WebSocket or its own built-in LLM (Retell LLM), cold, warm and agentic transfers, voicemail detection, signed webhooks, branded and verified caller ID, and in-platform voice cloning through ElevenLabs, Cartesia and others.
- **RingCentral (RingEX) has no public SIP trunk that Retell could import a number through.** RingCentral staff confirmed this in March 2026. BYOC is a carrier-into-RingCentral feature for multinational customers. RingEX gives real-time two-way audio only by registering as a phone device (the softphone/WebRTC SDKs, or manual SIP "Existing Phone" credentials), and that would mean building your own media bridge. RingCX (the contact-center product) streams audio one way over gRPC and has a SIP bot (IVA) integration in which RingCX sends calls to the bot.
- **Practical path:** have Retell place the AI calls on Retell-purchased (or Twilio/Telnyx-imported) numbers, with Molly's voice cloned inside Retell on ElevenLabs or Cartesia. Then transfer to the recruiter's RingCentral DID or extension by PSTN number. Use the RingCentral APIs only for SMS, call logs and presence, not for the AI audio.

## A. HeyGen

### A1. Voice cloning, tiers, recording requirements, consent
- **What it is:** HeyGen Voice is HeyGen's own voice model, with two modes: Instant and Professional. https://developers.heygen.com/docs/models/heygen-voice.md
- **Instant clone**
  - One recording; only the first 3 minutes are used. 1–3 minutes of clear speech is recommended.
  - MP3 or WAV, up to 100 MiB. A silent recording fails. `remove_background_noise` defaults to true.
  - It can't be retrained; you create a new voice instead.
  - 39 languages are supported.
  - Source: https://developers.heygen.com/docs/voices/heygen-voice-instant-clone
- **Professional clone**
  - 1–10 recordings of the same speaker, at least 20 minutes in total. Silence counts toward the total, so trim dead air and overlapping speech.
  - It is a paid feature. Each voice uses one purchased slot, and each slot includes 5 pooled trainings per month.
  - Source: https://developers.heygen.com/docs/voices/professional-voice-clone.md
- **Plans (web app):** every plan includes voice cloning, but the number of clones varies: Free 1, Creator 40, Pro, Business and Team 70, Enterprise unlimited. https://help.heygen.com/en/articles/9834925-how-to-get-started-with-voices
- **API access:** creating clones over the API depends on workspace permission. You get `403` "The workspace is not allowed to create voice clones" if it isn't enabled. https://developers.heygen.com/docs/voices/heygen-voice-instant-clone
- **Consent and verification**
  - No speaker-verification step for voice clones appears in the API docs.
  - HeyGen's ethics page requires expressed consent of the depicted person for custom avatars. It also says HeyGen removes content where a person's "image, likeness or voice is used without their permission." https://www.heygen.com/ethics
  - A voice-specific verification flow is UNCONFIRMED.
  - Avatar consent has its own API: https://developers.heygen.com/docs/avatar-consent.md

### A2. Public API endpoints
Source for all of these: https://developers.heygen.com/docs/models/heygen-voice.md. Auth is an `X-Api-Key` header.

| Purpose | Endpoint |
|---|---|
| (a) Create a voice clone, instant or professional | `POST /v3/models/audio/voices` |
| (b) List your cloned voices | `GET /v3/models/audio/voices` (`type=public` returns HeyGen's public voices) |
| Get one voice | `GET /v3/models/audio/voices/{voice_id}` |
| Delete a voice | `DELETE /v3/models/audio/voices/{voice_id}` |
| (c) Standalone TTS, one completed WAV | `POST /v3/models/audio/tts` |
| Streaming TTS | `POST /v3/models/audio/tts/stream` |

- The TTS endpoints return audio, not video.
- TTS parameters: `voice_id` (must be an ACTIVE HeyGen Voice clone or a HeyGen public voice), `text` (1–5,000 characters), `model` (`heygen-voice-1` or `heygen-voice-1-turbo`), and `language`. https://developers.heygen.com/docs/voices/heygen-voice-speech.md
- The separate stock and designed voice catalog (`/v3/voices`) speaks only through `POST /v3/videos` (Third Party Speech). https://developers.heygen.com/docs/voices/overview.md

### A3. Streaming and real-time use
- **Streaming TTS output:** Server-Sent Events. Each audio event is a base64 standalone WAV part with a `part_index`, and the stream ends with `[DONE]`.
- **Audio format:** completed output is mono PCM16 WAV at 44.1 kHz. There is no output-format parameter, so there is no μ-law/8 kHz option for telephony.
- **Rate limit:** 30 requests per minute per workspace member, per endpoint. That is very low for a turn-by-turn phone agent.
- **Latency:** no figures published. `heygen-voice-1-turbo` is described as "lower latency," for instant voices only.
- Source for the four points above: https://developers.heygen.com/docs/voices/heygen-voice-speech.md
- **LiveAvatar** (real-time conversational avatars) has FULL and LITE modes, and LITE lets you bring your own LLM. Its docs don't mention audio-only output, telephony or SIP. https://developers.heygen.com/live-avatar.md
  - Audio-only telephony output: UNCONFIRMED (not documented).
  - LiveAvatar pricing is separate from API plans. https://help.heygen.com/en/articles/10060327-heygen-api-pricing-explained
- **Terms restricting cloned voices to HeyGen output:** no explicit clause found. UNCONFIRMED. Ask HeyGen before using a HeyGen voice for phone calls.

### A4. Using a HeyGen voice with Retell or ElevenLabs
- **Not possible as documented.**
  - Voices "belong to the workspace that created them." https://developers.heygen.com/docs/models/heygen-voice.md
  - No export of the voice model is documented.
  - Retell's `voice_provider` values are elevenlabs, cartesia, minimax, fish_audio, platform and inworld. HeyGen is not one of them. https://docs.retellai.com/api-references/clone-voice.md
- **The reverse direction works:** HeyGen can connect a third-party ElevenLabs Professional Voice Clone, which needs a paid ElevenLabs account. https://help.heygen.com/en/articles/9834925-how-to-get-started-with-voices
  - So an ElevenLabs clone of Molly can serve both HeyGen videos and Retell calls.
- **The only way to use HeyGen TTS on calls** is a fully custom media stack, such as your own SIP/Twilio media pipeline that calls HeyGen's SSE TTS. Retell has no "external TTS" hook (UNCONFIRMED that none exists; none was found in the docs).
- **Re-cloning instead:** you can also re-clone Molly from the same consented raw recordings in ElevenLabs, Cartesia or Retell.

### A5. HeyGen pricing
- **HeyGen Voice API:** $30 per million characters, with no minimums. The Professional Voice Clone add-on is listed at "$29/mo and $99/mo." https://www.heygen.com/heygen-voice
- **Instant clones over the API:** free during the preview. https://developers.heygen.com/docs/models/heygen-voice.md
- **API pricing article:** lists "Speech (Starfish): $0.12 per min." API credits are bought in USD, expire after 12 months, and there have been no free API credits since February 2026. https://help.heygen.com/en/articles/10060327-heygen-api-pricing-explained

## B. Retell AI

### B1. Outbound calls and phone numbers
- **Create a call:** `POST https://api.retellai.com/v2/create-phone-call`
  - Required: `from_number` and `to_number`. `from_number` "Must be a number purchased from Retell or imported to Retell."
  - If `from_number` is a Retell-purchased number, only US destinations are supported.
  - Optional: `override_agent_id`, `retell_llm_dynamic_variables`, `metadata`, `idempotency_key`, `agent_override`, `custom_sip_headers`, `honor_internal_dnc`.
  - Source: https://docs.retellai.com/api-references/create-phone-call.md
- **Buying numbers**
  - Retell-managed numbers come from Twilio or Telnyx.
  - US $2/month, US toll-free $5/month, Canada $2/month.
  - Numbers can be bought only in the US and Canada, and can call 15 countries.
  - Source: https://docs.retellai.com/deploy/purchase-number
- **Importing numbers**
  - Endpoint: `POST /import-phone-number`.
  - Fields: `phone_number`, `termination_uri`, `sip_trunk_auth_username` and `sip_trunk_auth_password`, `transport` (TLS, TCP or UDP), and `inbound_agents` / `outbound_agents`.
  - Source: https://docs.retellai.com/api-references/import-phone-number.md
- **Custom telephony**
  - Two methods: Elastic SIP trunking (recommended) or Dial-to-SIP-URI through the Register Phone Call API.
  - Retell's SIP server is `sip:sip.retellai.com`.
  - Guides cover Twilio, Telnyx, Vonage, Avaya, Genesys, Five9 and Amazon Connect. **RingCentral is not mentioned.**
  - Source: https://docs.retellai.com/deploy/custom-telephony.md
- **RingCentral SIP trunk status**
  - RingCentral staff (Community Manager, 2026-03-24), answering a user who asked specifically about Retell: "Unfortunately, we don't have open/public SIP trunking API." https://community.ringcentral.com/developer-platform-apis-integrations-5/does-ring-central-support-sip-trunking-11735
  - An open RingCentral Ideas request for "SIP trunking support for third-party AI platforms like ElevenLabs" has status "New." It reports that RingCentral's SIP endpoints are built for device registration, not trunking, and that TLS certificate problems occur. https://ideas.ringcentral.com/forums/958505-developer-platform-apis-integrations/suggestions/50231841-enable-sip-trunking-support-for-third-party-ai-pla
  - RingCentral BYOC brings a customer's own local carrier into RingCentral's cloud PBX, through a gateway the customer owns, "for multinational customers." It is not documented as an outbound trunk to third-party AI. https://www.ringcentral.com/legal/BYOC-service-description.html
  - "Telephony as a Service" for third parties: UNCONFIRMED (no official doc found).
- **Porting:** porting a RingCentral number out to Twilio or Telnyx and then importing it into Retell is possible in principle. That is a carrier process; UNCONFIRMED in Retell docs.

### B2. Custom voices and voice cloning in Retell
- **TTS providers and per-minute prices**
  - Retell platform voices, MiniMax, Fish, Cartesia, OpenAI and Inworld: $0.015/min each.
  - ElevenLabs: Flash $0.040/min, Multilingual v2 $0.06/min, v4 Turbo and v3 Conversational $0.08/min, v3 and v4 $0.10/min.
  - Source: https://www.retellai.com/pricing
- **Cloning inside Retell:** `POST https://api.retellai.com/clone-voice` (multipart form).
  - Fields: `files` (up to 25 files for ElevenLabs; 1 file for Cartesia and MiniMax; 3 for Inworld), `voice_name`, and `voice_provider` (elevenlabs, cartesia, minimax, fish_audio, platform or inworld).
  - Source: https://docs.retellai.com/api-references/clone-voice.md
  - The same is available in the dashboard: voice selector, then "Add custom voice."
  - Recording guidance: "Record a single speaker with no background noise, music, or echo."
  - Limit: 100 custom voices per account.
  - Source: https://docs.retellai.com/build/voice.md
- **Importing a provider's voice:** `POST /add-community-voice`, with `provider_voice_id` and, for ElevenLabs only, `public_user_id`. This works for public or community voices. https://docs.retellai.com/api-references/add-voice.md
- **ElevenLabs bring-your-own-key / private clones:** not supported, according to a Retell support reply dated 2026-02-19. The suggested workarounds are to share the voice publicly or to re-clone it through Retell's Clone Voice API. https://community.retellai.com/t/enable-elevenlabs-byok-private-voice-clone-not-selectable/886 (community forum, not docs)
- **Consent:** neither Retell's clone docs nor its API reference mention a consent or verification step. UNCONFIRMED whether Retell's terms require one. Keep your own signed consent from Molly regardless.

### B3. Response engines, functions, interruptions, transfer
- **Response engines:** `retell-llm`, `custom-llm` (a WebSocket URL) or `conversation-flow`. https://docs.retellai.com/api-references/create-agent
- **Custom LLM WebSocket**
  - Retell opens the WebSocket to your `llm_websocket_url/{call_id}`.
  - Retell to your server: `call_details`, `update_only`, `response_required`, `reminder_required` and `ping_pong`.
  - Your server to Retell: `response`, `config`, `agent_interrupt`, `tool_call_invocation` / `tool_call_result`, `update_agent` and `metadata`.
  - Source: https://docs.retellai.com/integrate-llm/overview.md
  - Fields in a `response` event: `response_id`, `content`, `content_complete`, `end_call`, `transfer_number`, `digit_to_press`, `no_interruption_allowed` and `show_transferee_as_caller`. https://docs.retellai.com/api-references/llm-websocket.md
- **Function calling with a custom LLM**
  - Your own model does the tool calling. Retell carries out only `end_call`, `transfer_number` and `digit_to_press`, which are mutually exclusive in a single response.
  - Responses can be re-requested, so make tools idempotent.
  - Source: https://docs.retellai.com/integrate-llm/integrate-function-calling
- **Retell LLM custom functions**
  - HTTP call to your public URL. POST is the default and carries `name`, `call` and `args`.
  - Timeout defaults to 2 minutes and can be set from 1 second to 10 minutes.
  - Each request carries `X-Retell-Signature` (HMAC-SHA256). Results are capped at 15,000 characters. `max_retry` can be 0–5.
  - Source: https://docs.retellai.com/build/single-multi-prompt/custom-function
- **Interruptions and turn-taking**
  - `interruption_sensitivity` ranges 0–1 (default 1; 0 means the agent is never interrupted).
  - `responsiveness` ranges 0–1. `enable_backchannel` is off by default.
  - `denoising_mode` also affects behaviour.
  - Source: https://docs.retellai.com/api-references/create-agent
  - With a custom LLM, Retell discards a response if the user keeps talking and asks again with a new `response_id`. https://docs.retellai.com/integrate-llm/overview.md
- **Transfers**
  - Types: cold, warm and agentic warm.
  - Warm transfer supports a "Whisper Debrief Message" and hold music, and waits for a real person before debriefing.
  - Caller ID shown to the destination: the Retell agent's number or the user's number. The user's number depends on the provider; Telnyx numbers support it on cold transfers only.
  - SIP INVITE (the default) or SIP REFER.
  - Source: https://docs.retellai.com/build/single-multi-prompt/transfer-call.md
- **How transfer outcomes are reported**
  - Webhook events: `transfer_started`, `transfer_bridged`, `transfer_cancelled` and `transfer_ended`, with `transfer_destination` and `transfer_option`. https://docs.retellai.com/features/webhook-overview.md
  - `disconnection_reason` values: `call_transfer`, plus `transfer_bridged` and `transfer_cancelled` on the transfer agent's call in agentic warm transfers. https://docs.retellai.com/reliability/debug-call-disconnect

### B4. Webhooks
- **Voice events:** `call_started`, `call_ended`, `call_analyzed`, `transcript_updated`, `transfer_started`, `transfer_bridged`, `transfer_cancelled` and `transfer_ended`.
  - Default subscription: started, ended and analyzed.
  - Each delivery has a 10-second timeout and is retried up to 3 times.
  - Retell's IP is `100.20.5.228`.
  - Source: https://docs.retellai.com/features/webhook-overview.md
- **Signature verification**
  - Header: `X-Retell-Signature`, formatted `v={timestamp},d={hex_digest}`.
  - Method: HMAC-SHA256 over the raw body plus the timestamp, keyed with the **API key that has the webhook badge**. Reject timestamps older than 5 minutes.
  - SDK helpers: `Retell.verify(rawBody, apiKey, signature)` in Node, or `retell.verify(...)` in Python.
  - Source: https://docs.retellai.com/features/secure-webhook.md

### B6. Voicemail, caller ID, branded calling, A2P
- **Voicemail detection**
  - Setting: `voicemail_option`, with actions hangup, static_text, prompt or bridge_transfer.
  - Detection runs during the first 3 minutes of the call, and that window is not configurable.
  - Result: `disconnection_reason` = `voicemail_reached`.
  - Source: https://docs.retellai.com/build/handle-voicemail.md
- **Outbound caller ID:** must be a Retell-purchased or imported number (see B1).
- **Branded call (business name shown instead of the number)**
  - Requires a verified business profile. US numbers only.
  - Carrier name limits: T-Mobile and AT&T 32 characters, Verizon 15.
  - Processing takes 1–2 weeks.
  - Source: https://docs.retellai.com/build/telephony/branded-call.md
- **Verified number (reduces "Spam Likely" labels):** US only, needs a business profile, takes 1–2 weeks. https://docs.retellai.com/build/telephony/verified-phone.md
- **Spam-related failures:** Retell reports `marked_as_spam` and `network_blocked`. It also notes that repeated short calls from one number can cause `dial_failed`, so plan number rotation and pacing. https://docs.retellai.com/reliability/debug-call-disconnect
- **Do-not-call:** the `honor_internal_dnc` parameter, plus a DNC guide. https://docs.retellai.com/build/do-not-call.md
- **SMS:** Retell SMS requires a campaign application (A2P). https://docs.retellai.com/deploy/sms-campaign-application.md
- **TCPA / prior express written consent for AI-voice calls to mobiles:** this is a legal requirement not covered here. UNCONFIRMED in vendor docs; get counsel.

## C. RingCentral (RingEX, formerly MVP)

### C1. RingOut and Call Control
- **RingOut** is a two-leg call. RingCentral first calls the user's forwarding number, then connects it to `to`.
  - Create: `POST /restapi/v1.0/account/~/extension/~/ring-out` (body: `from`, `to`, `callerId`, `playPrompt`).
  - Status: `GET .../ring-out/{id}`. Cancel: `DELETE .../ring-out/{id}`.
  - Source: https://developers.ringcentral.com/guide/voice/ringout
  - No audio is delivered to the app; nothing on the page mentions media access. So it gives **no real-time audio**, as expected.
- **Call Control** makes, retrieves, controls and monitors calls. It is signalling only, with no media.
  - Session: `GET /restapi/v1.0/account/~/telephony/sessions/{id}`.
  - Requires the "Call Control" scope; requesting it triggers a review. https://developers.ringcentral.com/guide/voice/call-control
  - Party operations (path `/telephony/sessions/{sid}/parties/{pid}/`): `transfer` (body `phoneNumber`, `voicemail` or `parkOrbit`), `hold`, `flip`, `recordings`, mute via PATCH, and end via DELETE. https://developers.ringcentral.com/guide/voice/active-call-control
  - Warm-transfer guide: https://developers.ringcentral.com/guide/voice/warm-transfer

### C2. Ways to reach live call audio
- **Supervise API:** `POST /restapi/v1.0/account/~/telephony/sessions/{id}/supervise` (also a per-party variant).
  - Body: `mode`, `supervisorDeviceId` and `agentExtensionId`. "Currently, the only supported mode is `Listen`," so it is **listen-only**.
  - Audio is delivered to a supervisor SIP device. You can build that device with the softphone SDKs (TypeScript, .NET, JS).
  - Both extensions must be in a Call Monitoring Group.
  - Source: https://developers.ringcentral.com/guide/voice/supervision
- **WebRTC web phone SDK** (`ringcentral-web-phone`): for browsers; needs the "VOIP Calling" permission. https://developers.ringcentral.com/guide/voice/webrtc
- **Softphone SDK** (`ringcentral-softphone-ts`, Node, server-side): registers as a device and can auto-answer, receive remote audio and send audio.
  - This is described by a community member, with RingCentral staff saying "You can build one by yourself." https://community.ringcentral.com/developer-platform-apis-integrations-5/api-for-the-realtime-voice-bot-458 (community, not formal docs)
  - **This is the only two-way RingEX option.** It is a do-it-yourself media bridge (RTP to Retell or another agent stack). Retell would need its Dial-to-SIP-URI method, which is non-trivial; UNCONFIRMED feasibility.
- **Manual SIP credentials ("Existing Phone")** from the Admin Portal, via Set up manually using SIP. A third-party SIP client can register with these as a phone, not as a trunk. https://support.ringcentral.com/article-v2/Manual-Provisioning-How-get-SIP-Settings.html?brand=RC_US&product=RingEX&language=en_US
  - Whether this is licensed for AI or automated dialing: UNCONFIRMED.
- **RingCX only (contact center)**
  - Audio streaming: **one-way** gRPC over TLS, PCMU 8 kHz in 100 ms chunks, enabled by your RingCentral representative. https://developers.ringcentral.com/engage/voice/guide/workforce/call-streaming/getting-started
  - Bot/IVA SIP integration: RingCX sends an INVITE to your bot's SIP URI, exchanges JSON over SIP INFO, and returns the call to the workflow with Success, Failed or Disconnected. It is set up in Workflow Studio and secured by IP allowlist. https://developers.ringcentral.com/engage/voice/guide/bots
  - This could route RingCX calls to Retell over SIP. Retell compatibility is UNCONFIRMED.
- **Plans:** Voice APIs are included with all RingEX plans. https://developers.ringcentral.com/voice-api
  - App review: restricted scopes such as Call Control need justification. https://developers.ringcentral.com/guide/basics/permissions

### C3. SMS
- **Number setup:** numbers are not SMS-enabled by default.
  - US/Canada local numbers need TCR brand and campaign approval and must be linked to an active campaign.
  - Toll-free numbers need verification, and toll-free does not support MMS.
  - High volume uses the `A2PSmsSender` feature. The LowVolume tier allows at most 6,000 messages per day.
  - Check status with `smsCampaignInfo.status`, which must be "Confirmed."
  - Source: https://developers.ringcentral.com/guide/messaging/sms/sms-requirements
  - TCR registration help: https://support.ringcentral.com/article-v2/Setting-up-TCR-registration-assigning-numbers-to-SMS-campaigns.html?brand=RingCentral&product=RingEX&language=en_US
- **Send:** `POST /restapi/v1.0/account/~/extension/~/sms`.
- **Receive:** subscribe to the event filter `/restapi/v1.0/account/~/extension/~/message-store/instant?type=SMS`.
- Source for send and receive: https://developers.ringcentral.com/guide/messaging/sms/receiving-sms-mms

### C4. Webhooks and telephony events
- **Creating a webhook subscription**
  - Body: `eventFilters` plus `deliveryMode` {`transportType`: "WebHook", `address`}.
  - On creation, RingCentral sends a `Validation-Token` header. You must echo it back with HTTP 200 within 3,000 ms.
  - Renew with PUT or POST renew. Subscriptions can be set to effectively never expire.
  - Source: https://developers.ringcentral.com/guide/notifications/webhooks/creating-webhooks
  - A per-notification verification-token header: UNCONFIRMED on that page. One option is a secret in the URL query, as in the page's example.
- **Telephony session events**
  - Status codes: Setup, Proceeding, Answered, Disconnected and Voicemail. Order events by `sequence`.
  - Example filter: `/restapi/v1.0/account/{acc}/extension/{ext}/telephony/sessions`.
  - Requires the CallControl permission.
  - Source: https://developers.ringcentral.com/guide/voice/telephony-session-notifications
- **Transfer:** `POST .../telephony/sessions/{sid}/parties/{pid}/transfer` (see C1).

### C5. Scopes and auth
- **Scopes:** RingOut, CallControl, SMS, ReadAccounts, ReadCallLog, SubscriptionWebhook, VoipCalling and ReadPresence. https://developers.ringcentral.com/guide/basics/permissions
  - "Call Control (requires permission)" triggers a review. https://developers.ringcentral.com/guide/voice/call-control
- **JWT auth flow**
  - The app must be configured to accept JWT. Create the JWT credential in the Developer Console.
  - `POST https://platform.ringcentral.com/restapi/oauth/token` with `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer`.
  - Access tokens last about 2 hours and refresh tokens about 7 days. The JWT itself does not expire unless you choose otherwise.
  - Source: https://developers.ringcentral.com/guide/authentication/jwt-flow

## D. Voice-clone providers usable live with Retell

### ElevenLabs
- **Instant Voice Clone (IVC)**
  - Under 2 minutes of audio can work. https://elevenlabs.io/docs/eleven-api/concepts/voice-cloning
  - Included on Starter and above. https://elevenlabs.io/pricing
- **Professional Voice Clone (PVC)**
  - At least 30 minutes of audio; 2–3 hours is best. Single speaker only.
  - Training takes about 3–6 hours, and the fine-tuning step alone 6–24 hours.
  - Requires Creator or above, with slots: Creator and Pro 1, Scale 3, Business 10.
  - Source: https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning
- **Verification ("voice captcha")**
  - The speaker reads verification lines on similar equipment before fine-tuning starts.

## Recommended production path

1. **Consent first.**
   - Get a written, signed consent and licence from Molly covering AI voice cloning for outbound recruiting calls, revocation and retention.
   - Record 2–3 minutes (instant clone) and, ideally, 30+ minutes (professional clone) of clean, single-speaker, uncompressed audio.
2. **Voice:** clone Molly inside Retell (`POST /clone-voice`) with **Cartesia** (cheapest, low latency) or **ElevenLabs** (quality). A/B test both. Do not depend on HeyGen for calls (A4).
   - If you also want the same voice in HeyGen videos, create it as an ElevenLabs voice on Molly's own account and connect it to HeyGen.
3. **Telephony**
   - Buy Retell numbers (Twilio-backed; $2/month), or import Twilio or Telnyx numbers by SIP. Apply for **Verified number + Branded call**.
   - Use local-presence numbers and keep each number's daily attempts low.
4. **Agent:** start with Retell LLM plus custom functions for ATS lookups and lead updates. Move to the custom LLM WebSocket only if you need full control.
   - Turn on voicemail detection with a static message.
   - Turn on `honor_internal_dnc`.
5. **Handoff to a human:** do a warm transfer to the recruiter's RingCentral direct number or `+main*ext`, as a normal PSTN transfer. Show the lead's caller ID if your provider supports it (Twilio numbers support it on warm transfers).
6. **Backend events**
   - Retell webhooks, verified with `X-Retell-Signature`, feed the CRM with `call_analyzed` and transfer events.
   - RingCentral JWT app with ReadCallLog and ReadAccounts scopes to tie the recruiter's leg to the lead.
   - Add SMS only after TCR approval.
7. **Not for v1:** building a RingEX softphone media bridge. Reconsider only if calls *must* come from RingCentral numbers (alternative: port numbers to Twilio).

## Account-level tests the owner must run

1. **HeyGen**
   - Call `GET /v3/models/audio/voices` with your API key.
   - Try `POST /v3/models/audio/voices` (instant) to see whether the workspace returns 403. Check the plan on the Usage page.
   - Ask HeyGen support in writing whether HeyGen voice clones or TTS output may be used in live phone calls.
2. **RingCentral**
   - Find out which product the account has: RingEX, RingCX or both. Check the edition.
   - Is the Call Control scope approved for the app?
   - Is TCR brand and campaign registration "Confirmed" (`sms-configuration`)?
   - Is a Call Monitoring Group set up?
   - Ask your RingCentral representative about any SIP trunk or BYOC option and RingCX audio streaming or IVA.
3. **RingCentral transfer target:** place a test call to the recruiter's DID or `+main*ext` from a non-RingCentral number. Confirm it rings the recruiter app and that the caller ID is displayed.
4. **Retell**
   - Create a workspace and clone Molly's voice (Cartesia and ElevenLabs).
   - Make test calls to the team's mobiles.
   - Measure latency, voicemail detection and warm transfer to RingCentral, and whether user-number caller ID shows on transfer.
   - Check webhook signature verification and the concurrency limit.
5. **Retell number reputation:** apply for the business profile, verified number and branded call (1–2 weeks). Check how the calls display on AT&T, Verizon and T-Mobile handsets.
6. **ElevenLabs** (if used): Molly completes the PVC voice-captcha on her own account. Confirm that cloning via Retell is acceptable to both vendors (UNCONFIRMED).
7. **Legal:** TCPA/FCC consent for AI-voice calls to mobile numbers, an AI disclosure script, state call-recording laws, and DNC scrubbing.
